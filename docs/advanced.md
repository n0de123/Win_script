# Advanced Usage

## Run Without Menu

You can generate and run the installer directly:

python setup_installer.py 2

(optional future feature)

## USB Deployment

Put the tool on a USB drive with installers.
Run on any PC.

## Company Deployment

Use with GPO or Intune by launching install_all.ps1.

## Custom PowerShell Editing

You can manually edit install_all.ps1 if needed.

## Offline Deployment

All installers are local. No internet required.
