# 🚀 Auto Install Windows Software

A simple and powerful tool to automatically install multiple Windows programs using Python and PowerShell.

Un outil simple et puissant pour installer automatiquement plusieurs logiciels Windows à l’aide de Python et PowerShell.

---

## 📌 Description

### 🇬🇧 English

This project helps you quickly configure a Windows PC.

You just need to:

1. Run the Python script  
2. Put your `.exe` and `.msi` installers into a folder  
3. Configure silent install options (optional)  
4. Generate a PowerShell script  
5. Install everything automatically

No manual clicking. No setup windows. Fully automated.

---

### 🇫🇷 Français

Ce projet permet de configurer rapidement un PC Windows.

Il suffit de :

1. Lancer le script Python  
2. Mettre les fichiers `.exe` et `.msi` dans un dossier  
3. Configurer les options silencieuses (optionnel)  
4. Générer un script PowerShell  
5. Tout installer automatiquement

Plus besoin de cliquer partout. Installation 100 % automatisée.
